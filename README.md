# VORTEX Streetwear - E-Commerce & Admin Management System

ระบบเว็บไซต์ร้านค้าเสื้อผ้าสตรีทแวร์มินิมอล **VORTEX** ในธีมสี **ขาว-ดำ (Black & White)** พร้อมระบบสมาชิก (Authentication), การควบคุมสิทธิ์การสั่งซื้อ และระบบหลังบ้านสำหรับผู้ดูแลระบบ (Admin Dashboard) แบบครบวงจร

---

## โครงสร้างไฟล์ทั้งหมดในโฟลเดอร์ `Web/`

```text
Web/
├── index.html              # หน้าร้านค้าหลัก VORTEX (หน้าแรก, หมวดหมู่, Flash Sale, สินค้า, ตะกร้า, สั่งซื้อ)
├── admin.html              # ระบบหลังบ้านแอดมิน (สถิติภาพรวม, จัดการสินค้า CRUD, จัดการออเดอร์/เลขพัสดุ)
├── login.html              # หน้าเข้าสู่ระบบและสมัครสมาชิก (พร้อมปุ่ม Quick Demo เข้าสู่ระบบด่วน)
├── style.css               # สไตล์ชีทหลัก VORTEX B&W Theme รองรับ Responsive ทั้งมือถือและคอมพิวเตอร์
├── app.js                  # ศูนย์กลางตรรกะระบบ Auth, Storefront, LocalStorage CRUD และ Admin
└── README.md               # คู่มือการใช้งานและเอกสารอธิบายระบบ
```

## 1. ระบบสมัครสมาชิก & เข้าสู่ระบบ (Auth System)

### บังคับเข้าสู่ระบบก่อนสั่งซื้อ:
- ผู้ใช้ทั่วไปสามารถเปิดดูหน้าร้าน รายละเอียดสินค้า ดูรูปภาพ เลือกไซส์ และอ่านรีวิวได้โดยอิสระ
- **เมื่อกดปุ่ม "เพิ่มลงตะกร้า" (Add to Cart), "ซื้อตอนนี้" (Buy Now) หรือ "สั่งซื้อสินค้า" (Checkout)**:
  - หากยังไม่ได้เข้าสู่ระบบ ระบบจะแสดงหน้าต่างแจ้งเตือนและนำทางไปยังหน้า `login.html` ทันที
  - ไม่อนุญาตให้สั่งซื้อหรือเพิ่มสินค้าจนกว่าจะเข้าสู่ระบบสำเร็จ

### หน้าเข้าสู่ระบบ & สมัครสมาชิก (`login.html`):
- มีแท็บสลับหน้า "เข้าสู่ระบบ (Sign In)" และ "สมัครสมาชิก (Sign Up)" ได้อย่างราบรื่น
- บันทึกข้อมูลสมาชิกลงใน `LocalStorage`
- **บัญชีทดสอบเริ่มต้น (Quick Demo):**
  - **ผู้ดูแลระบบ (Admin)**: `admin@vortex.com` / รหัสผ่าน: `admin123` (สามารถเข้าใช้งานหน้าร้านและหน้า `admin.html` ได้)
  - **ลูกค้าทั่วไป (Customer)**: `user@vortex.com` / รหัสผ่าน: `user123` (ช้อปปิ้ง สั่งซื้อสินค้า และดูประวัติพัสดุ)
  - มีปุ่มคลิกเดียวเพื่อล็อกอินด่วนบนหน้า `login.html` ได้ทันที

## 2. ระบบจัดการสำหรับแอดมิน (Admin Dashboard - `admin.html`)

### การป้องกันสิทธิ์ (Route Guard):
- ระบบจะตรวจสอบสิทธิ์อัตโนมัติ หากผู้ใช้ไม่ใช่บัญชี `admin` จะไม่สามารถเข้าถึงหน้าแดชบอร์ดได้ และจะถูกส่งกลับไปหน้าล็อกอิน

### สรุปสถิติภาพรวม (Dashboard Stats):
- ยอดขายรวมทั้งหมด (คำนวณจากยอดคำสั่งซื้อจริง)
- จำนวนคำสั่งซื้อทั้งหมด
- จำนวนสินค้าในร้านค้า
- จำนวนสมาชิกลูกค้าในระบบ

### ระบบจัดการสินค้า (Product CRUD):
- **เพิ่มสินค้าใหม่ (Create)**: ฟอร์มระบุชื่อสินค้า, ราคาขาย, ราคาเดิมขีดฆ่า, หมวดหมู่, ลิงก์รูปภาพ, เลือกไซส์ที่มี (S, M, L, XL, XXL), จำนวนสต็อก และสเปกผ้า
- **แก้ไขสินค้า (Update)**: สามารถคลิกแก้ไขราคา สต็อก ไซส์ หรือรูปภาพ และบันทึกมีผลที่หน้าร้านทันที
- **ลบสินค้า (Delete)**: ลบสินค้าที่ไม่ต้องการออกจากหน้าร้านทันที

### ระบบจัดการคำสั่งซื้อ & การจัดส่ง (Orders & Shipment):
- ตารางแสดงคำสั่งซื้อทั้งหมด พร้อมระบุชื่อและอีเมลของลูกค้าที่สั่งซื้อ
- ตัวกรองสถานะออเดอร์: ทั้งหมด, รอชำระเงิน, กำลังเตรียมจัดส่ง, จัดส่งแล้ว
- ปุ่มกด **"รับออเดอร์"** สำหรับเปลี่ยนสถานะเป็น 'กำลังเตรียมจัดส่ง'
- ปุ่มกด **"จัดส่ง/เลขพัสดุ"** สำหรับเปิดหน้าต่างระบุ **เลขพัสดุ (Tracking Number)** และเลือกบริษัทขนส่ง (**SPX Express**, Flash, Kerry, ไปรษณีย์ไทย, J&T)
- ข้อมูลเลขพัสดุจะเชื่อมโยงไปยังเมนู **"ออเดอร์ของฉัน / ติดตามสถานะพัสดุ"** ของลูกค้าที่หน้าร้านทันที
